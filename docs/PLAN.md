# Native Pi project tools

Goal: bounded Ripwire navigation and explicit reusable project checks. Preserve dirty OptChat; its normal tool-result path carries compact evidence. No prompt mutation, model inference, silent installs, or expensive auto-checks.

1. Fixed-verb Ripwire tool, exact root guard, bounded results/full logs outside repos.
2. Stack discovery and named recipe execution; no commands generated from model strings. Source/config/tool identities invalidate evidence.
3. Paged evidence retrieval; active/uncertain runs block replay.
4. Tests for execution, bounds, invalidation, uncertainty and actual Pi loading without inference.
5. Cheap DentAI/GeneXus checks; real builds only via explicit project recipes.
6. Local Pi install, dotfiles mirror, package docs; verify account/destination before publication.

Measure orchestration and context bytes separately from underlying build time. No whole-model speed/accuracy claim without a controlled model benchmark. Keep logs outside repositories/packages. Track completion in STATUS.md.
